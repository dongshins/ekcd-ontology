## 1. Purpose

This note documents the ontology-level revision from EKCD v1.1.2 to EKCD v1.1.5.

The revision is a non-breaking patch release focused on:

1. refining ontology-level publisher identification;
2. improving geographical clarity and discoverability by explicitly referring to Korea in the English ontology description;
3. updating ontology version metadata for the v1.1.5 release;
4. preserving all vocabulary terms and modeling semantics introduced in v1.1.2.

## 4. Ontology-level metadata revisions

### 4.1 Version metadata

- `owl:versionInfo` was updated from `EKCD v1.1.2` to `EKCD v1.1.5`.
- `dcterms:modified` was updated from `2026-05-25` to `2026-08-14`.
- `owl:priorVersion` and `dcterms:replaces` now identify the preceding public release, v1.1.2.

### 4.2 Description and discoverability

The English ontology description was revised to explicitly refer to historical and cultural resources of Korea. This change improves geographical clarity and discoverability while preserving the scope of EKCD as an ontology for Korean cultural heritage knowledge modeling.

### 4.3 Publisher metadata

The ontology-level publisher metadata was refined by adding the publisher URI `https://dh.aks.ac.kr/` and normalizing the English publisher label to `The Center for Digital Humanities, Academy of Korean Studies`.

## 5. Vocabulary compatibility

No classes, object properties, datatype properties, annotation properties, controlled confidence values, or other vocabulary terms were added, removed, or semantically redefined in this release.

EKCD v1.1.5 therefore remains compatible with ABox data created using the vocabulary terms of v1.1.2.

## 6. Release classification

EKCD v1.1.5 is classified as a non-breaking patch release focused on metadata quality, publisher identification, version documentation, and discoverability.
